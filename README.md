This repository is part of my **Undergraduate Thesis (TCC) in Geography at the University of Brasília (UnB)**. It demonstrates the development of an automated Python pipeline for the phenological monitoring and mapping of a critical fragment of **Semideciduous Dry Forest** (*Mata Seca Semidecídua*) located in the Gama District Park (*Parque Distrital do Gama*), DF, Brazil. 

I leveraged cloud computing and remote sensing technologies to analyze how this unique ecosystem responds to the severe seasonality of the Cerrado biome.

---

## 🎯 Main Project Objective

The primary objective of this project was to develop and validate an automated methodology to monitor and visualize NDVI dynamics within a remnant forest fragment. This serves as a low-cost, high-precision tool for local environmental management and scientific research.

To achieve this, I established the following technical objectives:
1. Access and process massive historical time series from Sentinel-2 (MSI) satellites without requiring robust local hardware.
2. Automate the cartographic process for generating multi-temporal comparative map sheets.
3. Generate high-resolution outputs ready for executive reports or academic publications.

---

## 🚀 Methodology

| Category | Technologies & Tools | Demonstrated Functionalities |
| :--- | :--- | :--- |
| **Data Science** | Python (Jupyter), NumPy, Pandas, Matplotlib | Matrix manipulation, multi-temporal data processing, custom data visualization. |
| **Remote Sensing** | Google Earth Engine (Python API), Sentinel-2 MSI | Cloud Computing, native NDVI calculation, radiometric calibration, QA60 cloud bitmasking. |
| **GIS & Cartography** | geemap, Matplotlib, Cartographic layout, UnB Research | Dynamic ROI detection, automated cropping, customized metric scale bar and North arrow, 300 DPI output. |
